🔐 Login Form Project

A simple and responsive Login & Sign Up Form built using React.js.

🚀 Features

- Login & Sign Up toggle
- Responsive design
- User-friendly interface
- Forgot Password option
- Form validation
- Clean and simple UI

🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS

📂 Project Structure

login-form/
├── src/
│   ├── App.js
│   ├── AuthForm.js
│   ├── App.css
│   └── index.js
├── public/
└── package.json

▶️ How to Run

npm install
npm start

The project will open in your browser at:

http://localhost:3000
